# La préparation

La consolidation des inventaires d'acquisitions et de paires interférométriques, et la construction des couches finales projetées sur les empreintes de bâtiments.

| script | ce qu'il calcule |
|---|---|
| [`build_couches_finales_overture.py`](build_couches_finales_overture.py) | Documente le seuil et les poids retenus pour chaque combinaison de méthode et de portée, puis projette ces paramètres sur l'ensemble des bâtiments pour produire les couches finales. |
| [`exp63_inventaire_paires_coherence.py`](exp63_inventaire_paires_coherence.py) | Inventaire consolidé des paires interférométriques employées pour les calculs de cohérence, rassemblées depuis cinq fichiers de schémas différents en un tableau unique portant le nom de zone de chaque paire. |
